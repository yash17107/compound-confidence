# House Money

Hackathon demo for FNB App of the Year — **financial inclusion and money confidence**.

**Don't YOLO the rent.** First pay life (rent, food, airtime, stokvel). Only leftover can become a paper FNB ETF. If leftover is R0, you sit. Sitting is the feature.

Rails are mocked FNB products, not live bank APIs: Easy Zero → eWallet → Shares Zero. WhatsApp "guaranteed 30%" tips get blocked.

## Try it

```bash
npm install
npm test
npm run dev
```

Open http://localhost:5173

- **Continue as Thabo** — taxi + SASSA in Soweto, R180 leftover. Try **Gig missed this week** to see the desk sit.
- **Continue as Nomsa** — care work in Tembisa, R200 leftover. Same leftover rule, different life.
- **Open a desk** — blank tape. You name the inflows and locked bills.

Languages: all 12 official languages, plus captioned SASL.
