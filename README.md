# Compound Confidence

Hackathon demo for FNB App of the Year — **financial inclusion and money confidence**.

This is a **live PWA on Vercel**, not a static website. The desk, leftover lock, forecast, AI coach and JSE quotes run as a React web app plus Python serverless APIs (`/api/coach`, `/api/forecast`, `/api/wrap`, `/api/market`). Add it to the home screen; the service worker keeps the shell on the phone.

**Stack it, track it, flex it.** First pay life (rent, food, airtime, stokvel). Only leftover can become a paper FNB ETF. If leftover is R0, you sit. Sitting is the feature.

Rails are mapped FNB products, not live bank APIs: Easy Zero → savings pocket → Shares Zero. Paper trading on live JSE prices. WhatsApp "guaranteed 30%" tips get blocked.
